# 🚀 Terraform Hands-On Repository

This repository contains various branches on **real-world Terraform hands-on implementations** across multiple AWS services, built and practiced as part of my **DevOps role (2+ years experience)**.  
The focus is on **production-ready IaC patterns**, not toy examples.

---

## 🎯 Purpose
- Practice and document Terraform concepts the way they’re used in real-world projects  
- Build reusable, scalable, and secure infrastructure on AWS  
- Strengthen troubleshooting, refactoring, and import workflows  

---

## 🧱 Covered Topics
- 🌐 VPC (subnets, routing, NAT, IGW, security)
- 🖥️ EC2, ASG, ALB
- ☸️ EKS (node groups, IAM, IRSA)
- 🔐 IAM (roles, policies, OIDC, least privilege)
- 🗄️ S3 (state, backend, versioning, encryption)
- 📦 Modules & workspaces
- 🔄 Import existing resources → manage via Terraform
- 🛡️ Security & best practices
- 📊 Terraform state, locking & drift handling

---

## ⚙️ Standards Followed
- Remote state & locking
- Modular & reusable code
- Clear variable and output structure
- Minimal manual changes (IaC first)
- AWS-aligned security practices


## 📌 Note
This repo evolves continuously as I explore **new Terraform scenarios, edge cases, and refactors** based on real production use.
